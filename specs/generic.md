# 通用自然语言 caption 规范

适用于：没指定模型，或查不到该模型的官方规范时兜底。

## 要素顺序

主体 → 动作 → 外观/服装 → 环境 → 构图/镜头 → 光线 → 色彩 → 风格/媒介 → 画内文字。

## 长度

- 图片：40–80 词。
- 视频：60–140 词，动作按时间推进写。

## 写法

- 只写看得见的：把「8K 超高清」「用 Blender 渲染」换成实际画面（光线方向、材质、景深）。
- 抽象形容词换具体名词：「漂亮」→「白色蕾丝、柔和侧光下的浅景深」。
- 一个主体一句话，别把三件事挤成一句。
- 画内文字用引号包住，并说明位置、大小、字体感觉。
- 多人物：点名写「Two girls: A ..., B ...」，别用代词 she/he 指代。

## 视频额外

- 镜头运动写清楚：`static shot` / `slow push in` / `handheld tracking` / `camera pans left`。
- 动作有先后：「先抬头，再把伞举到肩上」。
- 需要声音就写清：`ambient street noise`、`she says "..."`。

## 负面词

通用兜底（模型没给官方推荐时）：`lowres, bad anatomy, extra fingers, watermark, text`。
但如果模型文档有官方负面词，一律用官方的。
